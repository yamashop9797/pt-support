# PTサポート(理学療法士の業務サポートアプリ)第1段階

iPhoneのSafariで使う、ホーム画面に追加して使うアプリです。
データはiPhoneの中だけに保存し、外のサーバーやAIには送りません。電波がなくても動きます。

---

## 1. インターネットに公開する(GitHub Pages・無料)

パソコンでの作業です。所要時間は20〜30分ほどです。

### (1) GitHubのアカウントを作る
1. https://github.com/signup を開き、メールアドレス・パスワード・ユーザー名を決めて登録します。
   - ユーザー名はアプリのURLに入ります(例:`yamada-pt` → `https://yamada-pt.github.io/...`)。本名は避けるのがおすすめです。
2. 届いたメールの確認コードを入れて、登録を終えます。

### (2) 置き場所(リポジトリ)を作る
1. GitHubの右上「+」→「New repository」を押します。
2. Repository name に `pt-support` と入れます。
3. 「Public」を選びます(無料で公開するには Public が必要です。入っているのはアプリの部品だけで、患者さんのデータは入りません)。
4. 「Create repository」を押します。

### (3) ファイルを入れる
1. できたページの「uploading an existing file」というリンクを押します。
2. パソコンの `デスクトップ\理学療法士サポートアプリ` フォルダを開き、**中のファイルすべて**(フォルダは不要)をまとめてブラウザの画面にドラッグします。
   - アプリはフォルダを使わない形です。空のフォルダ(css・js・icons・tests)は入れなくてかまいません。
3. 下の「Commit changes」を押します。

### (4) 公開ボタンを押す
1. リポジトリの上の「Settings」→ 左の「Pages」を開きます。
2. 「Branch」で `main` と `/(root)` を選び、「Save」を押します。
3. 1〜3分待って画面を読み直すと、上に `https://ユーザー名.github.io/pt-support/` と出ます。これがアプリのURLです。

### アプリを直したとき
直したファイルを同じように「Add file」→「Upload files」で上書きします。
そのとき `sw.js` の `VERSION`(例 `v1.0.0` → `v1.0.1`)も上げると、iPhoneに新しいものが届きます。

## 2. 使い方(はじめの5つ)

### ① アプリを開くURL
`https://ユーザー名.github.io/pt-support/`(上の(4)で出たもの)を、iPhoneの**Safari**で開きます。

### ② ホーム画面への追加
1. Safariで上のURLを開く
2. 共有ボタン(四角から矢印が出ているマーク)→「ホーム画面に追加」→「追加」
3. これからは**ホーム画面のアイコン**から開きます(Safariで開いたときとはデータの置き場所が別です)

### ③ 暗証番号の設定
ホーム画面のアイコンから初めて開くと、呼び名と4けたの暗証番号を決める画面が出ます。
同じ数字を2回入れれば完了です。開くたびと、しばらく操作しないとき(設定で1〜30分)にロックがかかります。
忘れたときは、データを消して最初からになります(バックアップから戻せます)。

### ④ ショートカットで毎朝お知らせ
1. 「ショートカット」アプリ →「オートメーション」→「+」→「時刻」
2. 時刻(例 7:30)と「毎日」(または曜日)を選び、「すぐに実行」→「次へ」
3. 「Appを開く」を選び、「PTサポート」を選ぶ
4. 一覧に出ないときは「通知を表示」にして「PTサポートで今日やることを見ましょう」と入れる
※「URLを開く」はSafariで開いてしまうので使いません。

### ⑤ バックアップの取り方(月1回)
「設定」→「バックアップ」→「書き出す」→「"ファイル"に保存」で iCloud Drive などに保存します。
機種変更のときは、新しいiPhoneで「設定」→「読み込む」でそのファイルを選びます。
30日バックアップしていないと「今日」の画面でお知らせします。

## 第1段階でできること
- 患者管理(イニシャル・部屋番号・入院日・退院予定日・メモ、退院済みはアーカイブ)
- 新規担当チェックリスト(初回カンファの日/入院前の状態/InBody/FIM)
- 休みの日の登録(カレンダーをタップ)。お知らせ日が休みなら前の出勤日へ
- 自動お知らせ:サマリー(退院7日前から)、家屋調査(45日前・30日前・訪問翌日から報告書)、計画書(毎月1日)、病棟ADLカンファ(部屋番号から曜日を自動・前日)、各予定の前日
- 病棟ADLカンファ・退院前カンファの「伝えることの下書き」とコピー
- 今週の予定、iPhoneカレンダーへの登録(.ics・通知つき・イニシャルのみ)

## 第2段階でできること(バージョン2)
- ホーム:担当患者のタブ(アバター+イニシャル、横にスクロール)と「今日やること」だけ
- アバター:性別と年代(50代以下〜90代以上)で見た目が変わるイラスト
- 患者ページ:「入院から」「回復期に来て」「退院まで」「算定上限まで」の日数を大きく表示。中は 概要/記録/生活/書類 に分けた
- 概要:残っていること、予定と進み具合の一覧、装具(なし/あり/作製中・種類)、入院時のこと、ADL8項目
- 記録:毎日の記録(ボタンで選ぶ)、FIM(18項目・合計と利得)、InBody(数値と写真。写真は名前などを黒く塗りつぶしてから保存)
- 生活:住まい(市・町まで)、行き先(地図で調べる・手段・時間・‼️)、家族、介護保険・障害者手帳
- 書類:サマリーの下書き、家屋調査報告書の下書き、「AI用にコピー」
- 月の振り返り:毎月1〜7日にお知らせ。先月の数字とひとことメモ

## 評価の型(登録のときに選ぶ)
- 脳卒中:診断・損傷側・病巣。ブルンストローム・MAS・ROM・MMT・感覚・失調・形態・高次脳機能
- 整形:疾患・手術・患側・手術日(術後◯日)・荷重・禁止の動き。痛み(NRS)・炎症・ROM・MMT・周径・棘果長・歩行(補助具・10m・TUG・片脚立位)
- 脊損:国際基準(ISNCSCI)。キーマッスル左右10筋、触覚・痛覚28か所、肛門。神経学的レベル・AISを自動で計算(参考)。T6より上は「自律神経過反射に注意」
- どの型も「全部 正常にする」「前回と同じにする」があり、サマリーの下書きと「AI用にコピー」に入る
